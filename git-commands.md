# Git Commands Practice Record

## 1. Git Commands and Their Purpose

| Command | Purpose |
|---|---|
| `git --version` | Checks the installed Git version. |
| `git config --global user.name "Your Name"` | Sets the Git username. |
| `git config --global user.email "your-email@example.com"` | Sets the Git email address. |
| `git init` | Initializes a local Git repository. |
| `git clone <repository-url>` | Copies a remote repository to your computer. |
| `git status` | Shows the current status of files. |
| `git add .` | Stages changes for committing. |
| `git add <filename>` | Stages a specific file. |
| `git commit -m "message"` | Saves staged changes as a commit. |
| `git log --oneline` | Displays a concise commit history. |
| `git branch` | Lists local branches. |
| `git switch -c <branch-name>` | Creates and switches to a new branch. |
| `git switch <branch-name>` | Switches to an existing branch. |
| `git merge <branch-name>` | Merges another branch into the current branch. |
| `git remote -v` | Displays configured remote repositories. |
| `git push` | Uploads commits to a remote repository. |
| `git pull` | Fetches and integrates remote changes. |
| `git diff` | Shows changes that have not been staged. |
